# Icon filename catalog

Use these filenames for your own artwork. Add only the icons you want to replace;
missing icons use ZenOS and KOReader's bundled artwork. The builder adds lookup
aliases from `SIMPLEUI_NAMES` and `ALIASES` in `scripts/build-zen-packs.py`.
